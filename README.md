# 香调人格测评 · Scent Personality Quiz

MBTI 式的香调性格测评：78 道单选长问卷，答完得到你的香调人格画像、轮盘细分定位，以及按预算分档的参考香氛。纯前端单文件，本地离线可用，无需登录、无需联网。

## 使用方式

- **在线体验**：https://sharier1232.github.io/scent-personality-quiz/ ，无需下载，浏览器直接打开即可测评。
- 本地使用：直接用浏览器打开 `index.html` 即可开始测评。
- 无构建步骤、无后端、无外部依赖（CSS / JS / 题库 / 数据全部内联在一个 HTML 文件里）。

## 测评结构

- **78 道单选题**，分 9 组：场景回忆、心情情绪、性格社交、气味偏好、当前用香、细分侧重、生活方式与场合、感官与身体状态、审美与想象。
- **8 个香调家族（人格类型）**：

  | 图标 | 类型 | 英文 | 家族 |
  | --- | --- | --- | --- |
  | 🍊 | 清醒橙光型 | Bright Citrus | 柑橘 |
  | 🌸 | 柔瓣花语型 | Soft Floral | 花香 |
  | 🌿 | 林间清气型 | Green Fresh | 青绿 |
  | 🌊 | 清冷海盐型 | Cool Aquatic | 水生 |
  | 🪵 | 沉稳木韵型 | Warm Woody | 木质 |
  | 🟠 | 暖脂琥珀型 | Amber Embrace | 琥珀东方 |
  | 🍯 | 甜心丰腴型 | Gourmand Sweet | 美食 |
  | 🔥 | 深色沉烟型 | Smoky Depth | 干木皮革烟熏 |

- 参照 Michael Edwards 香气轮盘，每个家族拆 3 个细分侧重，共 **24 个子类**。
- **两层计分**：家族分决定主类型与副倾向，子类分决定主类型下的细分侧重。
- 结果给出匹配度前三类型，每类型分三档推荐参考香氛：贵款（1800 元以上）、一般（300–1800 元）、平价（300 元以下），每档 3 款。点开卡片可查看风格描述、留香时长、正装参考价与前 / 中 / 后调。

## 数据口径与免责说明

- 香氛仅为风格方向参考，**不构成购买推荐**，也不保证与实物一致；建议线下试香后再入手。
- 价格为常见正装规格参考价（容量 + 人民币），随品牌、容量、渠道、活动与批次波动，**非官网实时原价**。
- 留香时长为大众口碑公认区间；品牌官方一般只标注浓度（EDP / EDT / EDC）而不标留香小时，实际时长随肤质、季节、喷量与批次变化。
- 香调表为常见公开结构，不保证与某一批次完全一致。
- 页面提及的香水品牌与商标归各自权利人所有，本项目仅作学习与风格参考。

## 技术说明

- 单个自包含 HTML 文件，UTF-8 编码；题库、类型、子类与香氛数据均内联在文件内。
- 计分采用可解释的家族权重累加与排序，非机器学习推荐。
